## 游玩

- 免费网页游戏，手机和电脑浏览器均可游玩，无需下载安装。
- 通过手机中的聊天、照片、搜索、论坛和旧日志自行调查。
- 三条路线、三个结局；通关后可返回分支点，继续体验其他结局。
- 自动保存本机进度。设置中的“备份与恢复”支持导出和导入存档。
- 包含恐怖图像、突然惊吓和灵异情节。

游戏内的威信、佰度、薪浪围博、biss等均为虚构界面；游戏内搜索、账号和消息均为本地剧情模拟，无需使用真实账号。存档保存在当前浏览器，不上传到服务器。更换设备、域名或浏览器前，请先导出存档。

## 本地运行

需要 Node.js，无需安装依赖：

```sh
node server.cjs
```

随后打开 http://localhost:5193/ 。Windows 也可双击“启动游戏.cmd”。
