## 游玩

- 免费网页游戏，手机和电脑浏览器均可游玩，无需下载安装。
- 通过手机中的聊天、照片、搜索、论坛和旧日志自行调查。
- 三条路线、三个结局；通关后可返回分支点，继续体验其他结局。
- 游戏时间到次日06:00，若尚未达成任何结局，将进入超时失败界面；可返回分支点重试。
- 自动保存本机进度。设置中的“备份与恢复”支持导出和导入存档。
- 包含恐怖图像、突然惊吓和灵异情节。

游戏内的威信、佰度、薪浪围博、biss等均为虚构界面；游戏内搜索、账号和消息均为本地剧情模拟，无需使用真实账号。存档保存在当前浏览器，不上传到服务器。更换设备、域名或浏览器前，请先导出存档。

## 本地运行

需要 Node.js，无需安装依赖：

```sh
node server.cjs
```

随后打开 http://localhost:5193/ 。Windows 也可双击“启动游戏.cmd”。

## 项目

本仓库包含完整的静态游戏代码和美术资源。GitHub Pages 直接从 `main` 分支根目录部署，无需构建。所有资源使用相对路径。

游戏图像包含使用生成式 AI 制作的素材。公开仓库用于发布和保存游戏，不代表放弃作品权利；本仓库暂未授予单独的开源许可。


## 启动封面与资源预下载

打开首页可一键下载完整游戏资源（约192MB），支持进度显示、暂停、刷新后续传、失败重试和新版本增量更新。下载完成后进入游戏，已有存档保留；下载期间不运行游戏计时。也可选择直接在线游玩。缓存保存在当前浏览器，清除网站数据会同时清除本机缓存和存档。

发布前运行 `node build-resources.cjs` 更新资源大小、SHA256和版本清单，再一起发布 `resource-manifest.js` 与 `resource-worker.js`。首页为 `index.html`，游戏主体为 `game.html`；需要HTTPS或localhost以使用浏览器缓存功能。
